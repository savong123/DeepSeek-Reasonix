Windows 安装包和便携版现随包提供 Live Compact，默认关闭。

## 新增

- 在「设置 → 扩展 → 插件包」启用 `live-compact`。符合条件的回合结束后，它会缩减后续请求的上下文，不改原始会话记录，也不取代原有的大压缩。[功能说明](https://github.com/savong123/DeepSeek-Reasonix/blob/studio-v2.63.1/docs/LIVE_COMPACT.md)
- 同一个开关可停止后续小压缩，重启会保留选择。不会覆盖同名手装插件或自动装回卸载的插件；停用或卸载不撤销已有压缩视图。[功能说明](https://github.com/savong123/DeepSeek-Reasonix/blob/studio-v2.63.1/docs/LIVE_COMPACT.md)

<!-- lang:en -->

The Windows installer and portable zip now include Live Compact, off by default.

## New

- Enable `live-compact` in **Settings → Extensions → Plugin packages** to reduce context after eligible turns without changing the transcript or replacing native compaction. [Details](https://github.com/savong123/DeepSeek-Reasonix/blob/studio-v2.63.1/docs/LIVE_COMPACT.md)
- The switch stops new cuts and is remembered across restarts. Studio preserves manual installs and does not reinstall removed copies. Existing projections are kept. [Details](https://github.com/savong123/DeepSeek-Reasonix/blob/studio-v2.63.1/docs/LIVE_COMPACT.md)
